# Support

SessionAtlas is community-supported beta software.

## Before opening an issue

1. Check the latest [release notes](https://github.com/juliohuang/SessionAtlas/releases) and existing issues.
2. Confirm your operating system, SessionAtlas version, and affected AI CLI version.
3. Reproduce with a temporary `SESSIONATLAS_HOME` if possible.
4. Remove usernames, project paths, session contents, tokens, SSH details, and other private data from logs and screenshots.

Use the bug-report template for reproducible defects and the feature template for proposals. Maintainers do not promise a response or fix deadline.

## What is currently supported

- Windows 10/11 x64 desktop beta;
- CLI source builds on Windows, macOS, and Linux;
- the tools listed in the README;
- current and previous `0.1.x` beta releases on a best-effort basis.

## Security

Do not report suspected vulnerabilities in a public issue. Follow `SECURITY.md` once the repository's private reporting channel is enabled.
