# SessionAtlas 操作手册

本手册面向 SessionAtlas 的最终用户，介绍如何安装、扫描、浏览、搜索、分组、以及在选定项目里拉起 AI 编码会话。开发者架构说明见仓库根目录的 `README.md` 与 `CLAUDE.md`。

---

## 1. 它能做什么

SessionAtlas 是一个“跨 AI CLI 的项目与会话地图”：它通过共享 Rust 扫描核心维护 SQLite 索引，把各类 AI 编码 CLI（Claude Code、Codex、Kimi、OpenCode、Aider、Pi Coding Agent）访问过的项目汇总成一张可搜索的账本，并在右侧内嵌终端里一键续接 AI 会话。

一句话流程：**`sessionatlas scan` 建索引 → SessionAtlas 展示 → 选中项目 → 点工具启动标签 → 内嵌终端自动 `cd` 并运行该 CLI（带 `--resume` 时续接历史会话）。**

开发/发布验收请使用仓库内的[手工验收执行清单](manual-acceptance-checklist.md)，
其中列出了每个场景的操作、预期结果和证据记录格式。

---

## 2. 安装与首次运行

### 前置条件

1. **扫描由桌面版在进程内完成**
   桌面版会直接调用 Rust 扫描核心，不依赖外部扫描程序或额外语言运行时。
   若 `~/.sessionatlas/index.db` 不存在，首次启动会自动扫描一次并加载项目；已有索引不会在
   每次启动时重复扫描。需要单独使用命令行时，先安装 `sessionatlas` CLI，再在终端确认：

   ```bash
   sessionatlas --version   # 能输出版本即说明已安装
   ```

   安装方式：`cargo install --path crates/sessionatlas-cli --locked`，或用仓库内的
   `cargo run -p sessionatlas-cli --` 运行。

2. **数据库位置**
   - 索引库：`~/.sessionatlas/index.db`（由扫描核心维护，SessionAtlas 只读）
   - 偏好库：`~/.sessionatlas/prefs.db`（由 SessionAtlas 维护：分组、外部打开器、远程服务器和项目忽略规则，跨 rescan 持久化）

### 运行

- 开发模式（带前端热重载，Rust 改动自动重建）：

  ```bash
  cargo tauri dev
  ```

- 产出安装包：

  ```bash
  cargo tauri build
  ```

首次启动若索引库缺失，顶部会显示首次扫描进度；成功后直接进入项目列表。若没有找到可信的
工具数据或目录不可读，左侧会说明下一步操作并提供“再次尝试”，不会把失败伪装成空索引。

## 3. 扫描索引

首次缺少索引时应用会自动扫描。后续需要更新索引时，点击顶部搜索栏右侧的 **RESCAN** 按钮。

- SessionAtlas 会在进程内调用 Rust 扫描核心原子更新索引，随后重新拉取项目列表。
- 扫描完成后，底部状态栏会显示 `scan complete · N projects`。
- 60 秒的自动刷新定时器会在**没有搜索词**时静默重拉 `list_projects`；只有当项目数或最新 `lastAccessedAt` 变化时才重渲染，避免打断你的操作。
- 任一路径层级中，只要某个目录名以 `.` 开头（例如 `.cache`、`.worktree`），该目录及其所有子项目都会自动隐藏；`foo.bar` 这类不以 `.` 开头的名称不受影响。本机列表、远程列表和搜索使用同一规则。

> 扫描失败常见原因：受支持工具的数据目录不可读或格式异常。失败的工具保留旧快照，
> 不会影响其他工具的扫描结果；检查数据目录权限后点 RETRY。

## 4. 浏览与搜索

### 界面分区

- **顶部控制台（deck）**：品牌字标、搜索框、RESCAN / SETTINGS 按钮、工具过滤芯片、时间窗过滤芯片。
- **左侧项目账本**：按最近访问时间倒序排列的项目条目，每条都显示来源标签：本机项目为“本地”，SSH 项目为“远程 · 机器名”；机器名与远程服务器设置中的可编辑名称一致。条目同时带工具色点、相对时间、`⋯` 更多按钮，选中后的项目概览也会重复显示来源，避免混淆本地与远程路径。
- **右侧会话区**：终端标签栏 + 视口；未打开会话时显示空态或选中项目的启动面板。
- **底部状态条**：元信息（instr / proj / sess / last / sync）、状态文案、快捷键提示。

### 搜索

- 顶部搜索框输入即触发（200ms 防抖），走 SQLite FTS5 全文检索，**命中整个索引**，不只是当前可见窗口。
- 支持按项目名、路径、片段匹配。例如输入 `atlas-notes` 或 `C:\Demo` 都能命中。
- 搜索激活时，60 秒自动刷新会暂停（避免覆盖你的查询结果）。

### 过滤

两排芯片：

- **工具芯片**：由 `list_tools` 动态生成。已知 6 个工具（claude / codex / kimi / opencode / aider / pi）有固定配色，未知工具走稳定哈希色。点 ALL 清除工具过滤。
- **时间窗芯片**：`all` / `24h` / `7d` / `30d`，按 `lastAccessedAt` 过滤。注意：如果你的项目最近都没被访问，切到 `24h` 会让列表变空——这不是 bug，把芯片切回 `all` 即可。

### 忽略项目目录树

- 在项目的 `⋯` 菜单或右侧项目概览中点“忽略此目录树”，会隐藏该目录及其全部子项目。
- 在 **SETTINGS → 忽略列表** 中可以查看并恢复手动规则；自动的点目录规则固定生效，不需要逐项添加。
- 手动忽略只影响桌面版展示，不删除扫描索引。恢复后项目会立即重新出现，无需重新扫描。
- 远程忽略规则只作用于添加该规则的 SSH 服务器，不会误伤另一台服务器上的相同路径。

## 5. 项目分组

分组帮你把项目归类（如 "Work"、"Active"、"AI"），存于独立的 `prefs.db`，**跨 rescan 不会丢**。

- **新建分组**：打开 SETTINGS 抽屉（点 SETTINGS 按钮或按 `g`），底部 "Add group" 输入名字 → ADD。
- **分配项目**：在项目上点 `⋯` 打开弹窗，或选中项目后在右侧启动面板里，用 "Group" 下拉选择分组（选"未分组"即取消分配）。
- **折叠 / 展开**：点分组标题行切换。折叠状态存于浏览器 localStorage，**跨重启保留**。
- **重命名 / 删除**：在 SETTINGS 抽屉里改输入框（350ms 防抖自动保存）或点 `✕`。删除分组会级联清除其下项目的分配（项目回到"未分组"，不会被删）。

## 6. 打开会话

### 内嵌终端（推荐）

1. 在左侧选中一个项目（点条目，或 `↑↓` 导航后 `Enter`）。
2. 右侧出现启动面板，列出该项目记录过的工具（每个带会话数）+ "＋ plain shell"。
3. 点某个工具标签：
   - SessionAtlas 在右侧开一个新终端标签，真实 PTY 跑你的 shell，`cd` 到项目目录。
   - 若该工具有记录的 `lastSessionId`，挂接终端时由后端校验工具与会话标识，再按适配器写入对应的恢复参数（例如 OpenCode 为 `opencode --session <sessionId>`、Codex 为 `codex resume <sessionId>`）；否则只写工具命令。
   - "＋ plain shell" 只开一个普通 shell，不启动任何 AI 工具。
4. 多标签可并存，点标签切换；`✕` 关闭标签（会 kill 对应 PTY）。

> 终端库（xterm.js + addon-fit）本地 vendored 在 `frontend/vendor/`。若看到 "terminal library failed to load (offline?)" 提示，说明 vendor 文件没加载成功——重载窗口通常能恢复。

### 外部打开器

在启动面板 / 项目弹窗里，启用过的打开器会作为副操作显示（`--ember` 色）：

- **VSCode**：调 `code` 打开项目目录。
- **Explorer / Finder**：打开系统文件管理器。
- **Terminal**：开一个外部系统终端（Windows 优先 Windows Terminal，回退 cmd.exe）。
- **自定义**：在 SETTINGS 抽屉底部 "Add custom opener" 填标签 + 命令模板，`{path}` 必须是一个完整参数，例如 `subl {path}`。出于安全考虑，不接受 `cmd` / PowerShell / shell 脚本，也不能把 `{path}` 拼进另一个参数；其余内容按独立参数传给程序，不经过 shell 解释。

启用 / 禁用、改命令模板都在 SETTINGS 抽屉里完成（命令模板输入有 350ms 防抖自动保存）。

## 7. 键盘快捷键

| 按键 | 作用 |
|---|---|
| `/` | 聚焦搜索框（焦点已在搜索框时不触发） |
| `Esc` | 清空搜索词并刷新；若设置抽屉 / 项目弹窗开着则先关它们 |
| `↑` / `↓` | 在账本里上下移动光标 |
| `Enter` | 启动光标所在项目最近使用的工具（无工具则开普通 shell） |
| `g` | 打开 SETTINGS 抽屉 |

快捷键提示常驻底部状态条右侧。

## 8. 设置抽屉（SETTINGS）

点 SETTINGS 按钮或按 `g` 打开。包含：

- **Groups 区**：列出所有分组，每行可改名、看成员数、删除。
- **Openers 区**：列出内置 + 自定义打开器，每行可启用 / 禁用、改命令模板、删除（仅自定义可删）。
- **Remote servers 区**：添加免密 SSH 服务器。输入框已固定显示 `ssh`，通常只需填写 `user@host`；可追加 `-p 端口`、`-i 密钥文件`，也可直接粘贴以 `ssh` 开头的完整命令。显示名称可不填，默认使用主机名；添加后可直接在服务器列表中修改。保存前会先检测连接与 tmux，保存成功后会自动在后台完成首次扫描，扫描期间可以继续使用其它功能。服务器列表会显示上次成功扫描时间；首次扫描失败时仍显示“尚未扫描”，且后续失败不会覆盖已有成功时间。
- **忽略列表区**：展示自动点目录规则，并列出用户手动忽略的本机或远程目录树；点“恢复显示”即可删除对应手动规则。
- **底部表单**：在对应子页面新建服务器、分组或自定义打开器。
- 关闭：点背景遮罩、点 `✕`、或按 `Esc`。关闭时会重新拉取偏好以同步你在抽屉里的改动。

## 9. 故障排查

### 列表突然变空（"Archive empty ∅"）

数据其实还在（可去 `~/.sessionatlas/index.db` 确认）。常见原因：

1. **时间窗切到了 24h / 7d / 30d**
   若项目最近没被访问，时间窗过滤会把列表清空。把时间窗芯片切回 `all` 即可。

2. **搜索框残留了文字**
   按 `Esc` 清空搜索。

3. **所有匹配项目都在折叠的分组里**
   折叠的分组只显示标题行（带 `▸` 和计数），项目行隐藏。点标题行展开即可恢复。折叠状态存于 localStorage 跨重启保留；若想一次性全部展开，可在 DevTools（`F12`）Console 执行 `localStorage.removeItem('sessionatlas.collapsedGroups')` 后刷新。

4. **项目位于点目录中，或已加入忽略列表**
   点目录及其子目录会固定隐藏。手动忽略的项目可在 **SETTINGS → 忽略列表** 中点“恢复显示”。

### 首次扫描或重新扫描失败

- 若首次自动扫描失败，按左侧引导确认至少安装或使用过一种受支持的 AI CLI，并检查其数据目录权限，然后点“再次尝试”。
- 若仍报错，可在系统终端单独运行 `sessionatlas scan` 查看具体工具的诊断信息，再按提示修复数据目录权限或配置。

### 终端标签显示 "terminal library failed to load"

xterm.js vendor 文件没加载上。重载窗口（Ctrl+R）；若仍不行，检查 `frontend/vendor/` 下 `xterm.min.js`、`xterm.css`、`addon-fit.js` 是否存在。

### 会话启动后终端没反应

- PTY 启动失败会直接在终端里红字提示原因（如目录不存在）。
- 工具或会话标识不符合安全格式时，后端会拒绝自动启动；可先开 "plain shell" 检查工具是否安装。

### 偏好 / 分组丢失

偏好存在 `~/.sessionatlas/prefs.db`，与索引库分开。若你手动删过 `prefs.db`，分组、自定义打开器、远程服务器和手动项目忽略规则都会丢失；内置打开器恢复默认。索引库（`index.db`）由 `sessionatlas scan` 独立更新，不会影响偏好。

## 10. 元信息条说明

底部 meta strip：

| 字段 | 含义 |
|---|---|
| `instr` | 不同工具的种类数 |
| `proj` | 当前索引到的项目总数 |
| `sess` | 所有项目累计的会话数 |
| `last` | 最近一次访问的相对时间（每分钟自动刷新文案，不重拉数据） |
| `sync` | 最近一次访问的绝对时间（zh-CN 本地化） |

相对时间格式：`now` / `Nm` / `Nh Mm`（24h 内带分钟余量）/ `Nd`（7d 内）/ `Nw`（更久）。
