# 按远程 Git 仓库分组

项目列表的排序栏选择 **Git 仓库**，可把不同目录、克隆或 worktree 中指向同一远程仓库的项目归到一起。分组内按最近活动排序，可折叠，并保留原来的手动分组和手动顺序。

- 优先使用仓库配置中的 `origin`；没有 `origin` 时使用第一个配置的 remote。
- HTTPS、SSH URL 和常见 `git@host:owner/repo.git` 写法统一为 `host/owner/repo`。忽略末尾 `.git` 和斜线，保留路径大小写及非默认端口，避免误合并不同仓库。
- 不展示 URL 用户名、密码或查询参数。分组标题是文本，不作为可执行命令或链接。
- 未配置受支持的远程地址、读取失败和正在读取的项目分别显示，项目不会丢失。点击 **Git 仓库** 可重试失败项。
- 只有启用该视图才读取配置，最多并发两项，每项超时 8 秒，结果在本次运行中缓存 5 分钟。退出该视图后停止启动新的读取。
- 本机通过 Git 参数数组读取；远程项目通过已配置服务器的免密 SSH 读取。只读取仓库本地配置，不执行 fetch、pull、checkout，也不写入分组数据库。

本功能不按仓库所在文件夹分组，也不会把不同 fork 自动视为同一仓库。浏览器演示模式使用明确标为 `github.com/demo/...` 的示例分组。
